ASCENT 개인정보처리방침

시행일: 2026년 10월 13일

ASCENT는 운동 기록을 남기면 다음 무게와 횟수를 알려주는 앱입니다. 이 앱은 개인정보를 수집하지 않습니다.

1. 수집하는 정보

  • 앱은 이름, 이메일, 위치, 기기 식별자 같은 개인정보를 수집하지 않습니다.
  • 사용자가 입력한 운동 기록과 설정은 사용자의 기기 안에만 저장되며, 개발자나 제3자에게 전송되지 않습니다.

2. 인터넷과 권한

  • 앱은 인터넷 권한을 사용하지 않습니다. 광고와 분석 도구도 들어 있지 않습니다.
  • 안드로이드 9 이하 기기에서만, 백업·엑셀 파일을 다운로드 폴더에 저장하기 위해 저장공간 쓰기 권한을 요청합니다.

3. 백업 파일

  • 백업 파일과 엑셀 파일은 사용자가 직접 저장을 누를 때에만, 기기의 다운로드 폴더에 만들어집니다.
  • 만들어진 파일을 어디에 보관하고 누구와 공유할지는 사용자가 정합니다.

4. 데이터 삭제

  • 앱을 삭제하면 앱 안에 저장된 기록과 설정도 함께 삭제됩니다.
  • 다운로드 폴더에 저장해 둔 백업·엑셀 파일은 사용자가 직접 지워야 합니다.
